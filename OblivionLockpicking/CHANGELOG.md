# Changelog

All notable changes to the OblivionLockpicking mod will be documented in this file.

## [1.0.0] - Initial Release

- Lockpicking plays like Oblivion's tumbler lock, recreated for KCD2: push each tumbler up and set it while it pauses at the top.
- Tumbler speeds and pauses match how Oblivion's tumblers move.
- No Oblivion code, art or sound is used: the lock art is made for this mod, and the sounds are the game's own.
- A mistimed set can break the pick and pauses the controls for a moment, with no failure animation, so the view stays steady.
- A mistimed set keeps some set tumblers, more with a higher Thievery level.
- Thievery, perks and buffs slow the tumblers down. Experience, noise and crime stay the game's own.
- Two lock styles in 15th-century Gothic ironwork, rusty common and gilt fancy, richer on harder locks.
- Keyboard, mouse and controller support with Oblivion Remastered's controls, and every key can be changed.
- The lockpicking help screen and all texts in the game's 16 languages.
- Sounds for every push, click and fall through Sound Framework.
- Settings apply while the game runs, and the vanilla minigame can be turned back on.
