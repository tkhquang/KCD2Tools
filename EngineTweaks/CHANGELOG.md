# Changelog

All notable changes to the EngineTweaks mod will be documented in this file.

## [0.1.0] - Initial Release

- Removes the freezes that grow with the number of items Henry carries: beds, menus, loot and trade screens.
- Transferring all items to or from a container no longer freezes the game.
- Each engine fix has its own switch in the INI, and changes apply while the game runs.
- Replaces the game's two item list files, so another mod that replaces them wins or loses by load order.
